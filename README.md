# Exam Seat Management & Allocation System

A MERN Stack application for managing exam candidates, sessions, physical seats, and seat assignments.

## Project Structure

```
exam-seat-management/
├── backend/   → Node.js + Express + TypeScript + MongoDB
└── frontend/  → React + TypeScript + Vite
```

## Development Phases

This project is implemented phase-by-phase.

| Phase | Description |
|-------|-------------|
| 1  | Project Setup & Folder Structure |
| 2  | MongoDB Configuration |
| 3  | Common Infrastructure & Error Handling |
| 4  | Authentication & Authorization |
| 5  | Exam Management |
| 6  | Session Management |
| 7  | Candidate Management |
| 8  | Seat Management |
| 9  | Seat Assignment |
| 10 | Automatic / Bulk Allocation |
| 11 | Seat Map & Vacancy Management |
| 12 | System Failure Handling |
| 13 | Seat Reassignment |
| 14 | Candidate Session Transfer |
| 15 | Assignment History & Audit |
| 16 | Transactions & Concurrency |
| 17 | Admin Dashboard APIs |
| 18 | Validation & Security |
| 19 | Testing |
| 20 | Real-time Updates (Socket.IO) |
| 21 | React Frontend Integration |
| 22 | Deployment |
